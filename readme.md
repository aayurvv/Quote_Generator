# ✨ InspireMe - Quote Generator

A beautiful, interactive quote generator that inspires you daily with motivational quotes from famous personalities.

## 🚀 Features

- **Random Quotes** - Get a new inspiring quote with one click
- **Favorites** - Save quotes you love (persisted in browser)
- **Share** - Share quotes on Twitter or copy to clipboard
- **Keyboard Shortcuts** - Space for new quote, F for favorites
- **Responsive** - Works on all devices
- **Beautiful UI** - Modern design with smooth animations

## 🛠️ Tech Stack

- HTML5
- CSS3 (with animations)
- Vanilla JavaScript
- Font Awesome Icons
